# How To: Brain Computer Interfaces (BCI)

In this folder we aim to build a simple introductory step by step explanation on how to build BCI-Systems. 

A BCI can be implemented using either Motor Imagery (MI) (a non-phase locked stimulus), or using a P300 (a phase locked stimulus). 
In order to do so there are specific steps that should be followed which we will be implementing using Python and various packages (PsychoPy, mne, etc). 

The respective implementations for either MI or P300 can be found in the `ipynb` files you can find in this folder. 

This is **just a blue print** so modify it to your hearts desire and needs.
